Arachnophobia Patch for Morrowind

The mod is maintained as two independent packages:

- OpenMW/: optional Static Switching System replacements for OpenMW.
- MWSE/: optional Dynamic Object Replacer replacements for MWSE.

Each directory is a complete package with its own FOMOD installer, player readme, all replacement meshes and animations, optional moss web textures, and the OAAB web-trap ESP. Install the package for your engine. Both installers offer visual-only mode and independent vanilla, OAAB_Data, and Tamriel_Data selections. Runtime frameworks remain external dependencies, as listed in each package's readme.

Release archives

Run python tools/build_release.py to create:
- dist/Arachnophobia Patch-OpenMW-1.6.0.zip
- dist/Arachnophobia Patch-MWSE-1.6.0.zip

Each archive opens directly to its own FOMOD and component folders. It does not need files from the other archive or from this development workspace.

Validation

Run python tools/validate_support.py --archives after building. Development checks require PyYAML, jsonschema, and the local SSS reference schema. OPENMW_VALIDATION.md records runtime coverage and remaining gameplay checks. Development tools, references, and validation caches are excluded from both archives.
