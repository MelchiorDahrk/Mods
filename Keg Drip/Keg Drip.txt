==============================
	Keg Drip
by Melchior Dahrk & Greatness7
==============================

There is an unused texture in Morrowind's files called "tx_alpha_kegdrip00". It appears that Bethesda intended to make leaky taps at some point during development but never followed through. This mod takes that texture and adds a dripping effect to select kegstands in the game. Along with the visual effect, you'll notice a subtle dripping sound to increase the immersion.

This mod covers both the common and dunmer style kegstands, the unused "furn_winekeg00" model, and the additional Tamriel Data kegstands. The drip is placed as a separate effect at the keg's position, rotation, and scale. The original keg stays visible and keeps its own mesh, including any mesh replacer you have installed. Uncaught drips form a puddle using the included puddle mesh.

Detects kegs of any object type, including those added by mods, that use one of these mesh paths:
- f\furn_com_kegstand.nif
- f\furn_de_kegstand.nif
- f\furn_winekeg00.nif
- hf\f\hf_furn_kegstand_01.nif
- hr\f\hr_furn_kegstand_01.nif
- sky\f\sky_furn_n_m_keg_01.nif

The keg must be upright (within 5 degrees). With puddles enabled, nearby cells are checked once per second. An enabled bucket or bowl within 22 units of the drip's landing point catches the drip; moving or picking it up leaves the drip running and starts a puddle below it.

Configuration
==============================

"Form puddles" is enabled by default. Change it in the Keg Drip MCM for MWSE, or in Options > Scripts > Keg Drip for OpenMW. The preference is saved between game sessions.

Turning puddles off removes existing puddles and stops the once-per-second checks. Buckets and bowls are checked once when a cell loads: a new drip starts only if a receiver is found. Once a drip has started, it stays on even if the bucket is moved or removed. Existing drips also stay on when you disable puddles. Turn puddles back on to resume periodic receiver checks and puddle formation.


Installation
==============================

Mod manager (FOMOD)
- Install the archive with a FOMOD-compatible mod manager and choose MWSE or OpenMW.
- Enable Keg Drip.ESP.
- For OpenMW, make sure the installed mod is included as a data directory and also enable Keg Drip.omwscripts, with Keg Drip.ESP loading first.

Manual installation

00 Core
- Includes the meshes, textures, sound, and shared Keg Drip.ESP. Install this module and enable Keg Drip.ESP, then install ONE of the two 01 modules below.

01 MWSE Version
- Install the MWSE folder into Data Files.

01 OpenMW Version
- Add as a data directory in the OpenMW launcher (or copy contents into your mod data directory). Enable Keg Drip.omwscripts with Keg Drip.ESP loading before the scripts file.
